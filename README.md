# Drone Programming Course 

A Drone Programming Course I did to Show my Understanding of Computer Vision Integration in Tello Drone

# Projects Covered

- Drone Surveillance
- Face Tracking
- Mapping System 

# Tools 

- Yolo
- Tello
- Cv2
- Pygame

# Notes

- In Drone Surveillance, You can Record Real Time Footage, while Flying the Drone & Taking Snapshots
- In Face Tracking, It will Detect Human Faces & Follow them, at Safe Distances
- In Mapping System, It will Trace the Drone's Journey on a Map as it Flies
- Make Sure to Install the Tello App on your Phone
- Make Sure to Turn on the Drone & Connect to its Associated Network
